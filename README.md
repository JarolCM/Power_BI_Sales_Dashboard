# Power BI Sales Dashboard

Interactive sales analysis dashboard built with **Power BI**, using the Superstore Sales dataset. The project focuses on sales performance, profitability, and trends over time through data cleaning, dimensional modeling, DAX measures, and interactive visualizations.  

## Project Overview

The goal of this project is to transform raw sales data into an interactive dashboard that provides insights into:

- Geographic distribution of sales

- Key sales and performance indicators

- Sales performance over time

- Year-over-year performance

## Dataset Source

This project uses the **Superstore Dataset**, obtained from Kaggle and published by **Vivek Chowdhury (`vivek468`)**.

**Original source:**  
[Kaggle — Superstore Dataset](https://www.kaggle.com/datasets/vivek468/superstore-dataset-final)

The dataset is included in this repository for **educational and portfolio purposes** as:

`Superstore_Sales_Dataset.csv`

I do not claim ownership of the original dataset.

The data was cleaned, transformed, modeled, and analyzed in Power BI as part of this project.
